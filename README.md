# Aniruddha Mukherjee — Portfolio

A responsive React + Vite portfolio based on the supplied resume, designed for Java Full Stack / Backend interviews and freelance software enquiries.

## Run locally

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
```

## Resume and profile links

- Resume PDF is included in `public/Aniruddha-Mukherjee-Resume.pdf`.
- Email, GitHub, LinkedIn, and LeetCode links are populated from the supplied resume.
- Verify all content and links before publishing.

## Before publishing

- Add public GitHub repositories, demos, and screenshots for projects you can share.
- Add project details only if accurate and safe to disclose.
- Keep client source code, credentials, and confidential project details private.

## Deploy

Run `npm run build`, then deploy the generated `dist/` directory to Vercel, Netlify, or another static host.
